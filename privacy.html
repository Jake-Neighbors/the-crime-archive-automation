Privacy policy

This policy applies to the desktop verifier and first-comment tool used by the operator of The Crime Archive Daily YouTube channel.

Information the tool uses

After the operator authorizes access through Google, the tool uses YouTube API Services to retrieve channel and video information, an aggregate views report, and top-level comment records used to check whether the channel has already commented on the selected video.

When the operator explicitly runs the posting command, the tool sends the comment text, channel ID, and video ID to YouTube. A posted comment is displayed according to YouTube’s visibility and moderation settings.

Storage and sharing

The desktop tool keeps its OAuth refresh token on the operator’s computer so it can renew access. Its record of an attempted comment also stays on that computer. The verifier processes API responses during each run and does not write the retrieved views report or comment records to a separate data file. It displays check results in the terminal.

The tool communicates with Google and YouTube to authorize access, retrieve data, and submit an operator-approved comment. It does not sell YouTube data or use it for advertising. This public website does not ask for a Google sign-in or a token.

Revoke access or remove data

The operator can revoke the app’s access from Google Account permissions. The operator can also remove the app’s local OAuth files and comment attempt records. Comments published to YouTube can be managed on YouTube.

For privacy questions or removal requests, use the contact information on The Crime Archive Daily’s YouTube channel. Please do not send OAuth credentials with your request.

See the Google Privacy Policy for how Google handles information.
