The Crime Archive Automation

A desktop tool for the operator of The Crime Archive Daily YouTube channel.

What the tool does

The tool uses YouTube API Services to confirm the selected channel, retrieve a channel views report, and check an upload for an existing comment from the channel. The operator can preview a proposed first comment and explicitly choose to post it.

The tool requires the channel operator to authorize access through Google. This site provides information about the tool and its use of YouTube data.
